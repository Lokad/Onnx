## Fixed protocol and controls

Source `bb5d0ef` builds one binary for both phases. The exact candidate kernel
and frozen core are unchanged. Each phase uses eight fresh AMD EPYC 9V74 CPU-2
workers, normal .NET 10.0.8 tiering/GC, four mode rotations and their reversals.
The supervisor runs on CPU 0. Six shapes and nine batches per mode retain every
sample. Iterations are 32768/4096/256/256/32/32 for
8/30/padded128/128/512/padded512; rows are twelve times columns. Inputs and masks
match the earlier pinned workloads exactly.

Conditioning uses the same allocation-free batch routine as measurement,
for at least one second per shape/mode, all before any retained batch.
No JSON, hashes or console work occurs between measurements. The four slots
are actual frozen core, copied control, duplicate, and probe. Duplicate calls
the identical copied delegate. In control, probe is a third copy; only in
comparison does probe invoke the adaptive zero-block candidate.

Both copied controls pass the fixed 1% aggregate / 2% every-worker bounds in
the control phase. The largest worker deviation is 1.1954%. The comparison
keeps its duplicate control within the same bounds; its largest deviation is
1.5766%. Control batches last at least 46.462 ms; comparison at least 31.656 ms.
Every batch meets the predeclared 20 ms minimum. There is no measured GC,
recorded steal is zero, and maximum foreign CPU is 0.089805% of total machine
capacity. Peak sampled worker RSS is 147,746,816 bytes.

The control audit was completed and its exact hash verified by the comparison
