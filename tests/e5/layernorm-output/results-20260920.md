# LayerNorm final-transform proof — September 20, 2026

The standalone candidate **passes the local arithmetic and storage proof**:
915 cases, including 790 synthetic inputs and all 125 LayerNorm instances from
the five e5 cases. The actual archived product, its extracted copy and the
candidate agree in all 32,182,096 checked output values, including in-place
execution. Guard regions and input/parameter bytes remain unchanged.

Only the final `((x - mean) * inv) * scale + bias` loop changes. It processes
sixteen floats through two 512-bit double vectors; the mean, centered variance,
operation association, remaining vector groups and scalar tails retain the
original implementation. This changes no production code or default.

The local Windows i7-14700KF worker inherits logical CPU 2 before .NET 10.0.12
starts. Its ordinary float vector width is eight and hardware AVX-512 is absent.
The candidate therefore exercises the portable 512-bit implementation. Actual
AMD AVX-512 instructions, numerical behavior and performance remain unqualified.

Synthetic coverage includes empty and multiple rows, widths 1 through 1,536
with vector boundaries and tails, optional bias, three epsilons, near-constant
and large-offset rows, signed zero, subnormals, infinities and NaN payloads.
The C# proof compares every synthetic output bit against the actual private
product kernel. Python reconstructs all synthetic input hashes; synthetic
output arrays are not exported. Every real copy/candidate array is exported
and independently checked against captured product outputs and a scalar
centered-double calculation. All five full model outputs pass the unchanged
native scaled-error gate of 1e-4.
