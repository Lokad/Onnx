# Whisper recording qualification — September 19, 2026

Whisper now provides an explicit recording mode with segment timestamps,
unfinished-boundary recovery and token/window limits. Its Windows API and CLI
match native application decisions on the fixed examples below. The API accepts
up to ten minutes; this qualification covers approximately seventy seconds of
speech per constructed example, plus ten minutes of exact digital silence.
AMD recording mode, maximum-duration speech resources and broader conversation
accuracy remain open. The existing full encoder/logit numerical failures remain
unchanged.

Use [the recording API or CLI](README.md) with the pinned FP32 split export.
The thirty-second text API retains its behavior. No shared-core arithmetic or
default changed in this milestone.

All text tokens, timestamp tokens, interval boundaries, seek advances, stop
reasons and no-speech decisions agree. The first complete recording repeats with
identical results, including confidence values. The independently launched CLI
returns the exact same full JSON result as the API. Cross-engine confidence
values have maximum observed absolute difference 5.97052e-6; these observations
do not replace a tensor numerical gate.

The first window commits 26.76 seconds in Connected and 29.12 seconds in Shifted.
Each next window resumes at that boundary, preserving the unfinished suffix in
its predecessor's raw metadata. A token limit returns only completed segments;
the two-token example retains the raw word “also” for inspection but commits no
text or audio. An exhausted window limit retains the committed partial transcript.

Both complete examples use the same six prospectively selected utterances from
the [fixed labeled ASR subset](../../audio/accuracy/README.md), joined with 0.3
seconds of silence. Each has 160 normalized reference words and five word errors
(3.125% WER), identical across native and managed execution. The errors are kept:
SOMETIME / SOME TIME, MISSUS / MRS, FIFTEENTH / 15TH, and GREY / GRAY produce four
substitutions and one insertion under the unchanged normalization. Character
errors are 13/882 (1.4739%). The shifted example is correlated with the first;
these are boundary diagnostics, not independent conversation-accuracy samples.

The replay passes nine successful recording API requests: four policy cases,
one repeat, empty input, maximum-duration exact silence, and two concurrent
31-second silent requests. Ten invalid/canceled requests are rejected; subsequent
requests recover. Every actual PCM input and held result remains unchanged.
A real short-request regression retains all 22 original tokens and its native
text/stop decision. Managed inference loads no native ORT module.

The timestamp-mask fixture contains 50 cases executed by the original pinned
OpenAI implementation. Backend tests also cover three-token prefixes, independently
carried caches, incomplete tails, clipping, limits, cancellation and owned results.
The complete suites pass with the exact immutable replay DLLs: 2,989 backend tests
with 93 expected ISA skips, and 342 tensor tests. Twelve independent audit-contract
tests pass. All 510 native token choices and confidences were reconstructed from
their saved full logits. The complete native artifact set has 526 arrays and
45,713,516 values; this is reference/decision evidence, **not** a new managed
full-tensor comparison.

Inference was sequential on local Windows, CPU 2, SDK 10.0.204 and .NET 10.0.12,
with normal runtime/GC behavior, no environment overrides and a 16 GiB supervisor
guard. The managed process reported a peak of 11,298,021,376 bytes; sampled peaks

process, and 5,489,377,280 for native. These are finite resource observations,
