# Whisper recordings with segment timestamps

`WhisperTranscriber.TranscribeRecording` accepts finite mono 16 kHz PCM up to ten
minutes. `WhisperRecordingOptions.ForLanguage("en")` uses greedy decoding, up to
444 tokens per window and 256 windows per request (configurable from 1 to 512).
The existing `Transcribe` API remains limited to thirty seconds.

```csharp
var model = new WhisperTranscriber("models/whisper-large-v3-turbo");
var result = model.TranscribeRecording(pcm, 16000,
    WhisperRecordingOptions.ForLanguage("en"), CancellationToken.None);
```

```powershell
lonnx.cmd transcribe models/whisper-large-v3-turbo recording.wav --language en --recording --json
```

The CLI mixes/resamples supported local WAV files and rejects files exceeding ten
minutes before allocating PCM. `--max-tokens` limits each window;
`--max-windows` requires `--recording`. Recording mode is currently Whisper-only.

The model supplies segment timestamps with 20 ms resolution. Consecutive
timestamps divide segments; an unfinished suffix is decoded again starting at
the last completed boundary. Public intervals are clipped to the recording.
These are estimated segment times, not word alignment or speaker labels.
`Windows` retains all token decisions, including discarded unfinished text,
timestamps, EOS and confidence metadata. `Segments` and aggregate `Text` contain
only committed text. `ProcessedSeconds` is the committed position, which can be
earlier than the end of the last observed window. Check `StopReason` for
`Completed`, `TokenLimit`, `WindowLimit` or `NoProgress`. Cancellation throws
without returning a partial recording.

Every window has independent features, language/task prefix and caches. This
policy does not use previous text, temperature fallback, language detection or
translation. Per-window feature normalization differs from OpenAI's complete
long-form transcribe pipeline. The implementation adapts the timestamp and seek
rules from [pinned OpenAI Whisper source](https://github.com/openai/whisper/tree/86098128c0b4f24f0e2aa2994de830614b474227).
The original license is attributed in the Data project's NOTICE.txt. Timestamp
probability mass is evaluated in double log space with a strict greater-than
comparison; no tensor tolerance changes.

The ordinary suite executes 50 independent masks generated by the original
OpenAI `ApplyTimestampRules`, and exercises cache lengths, unfinished boundaries,
clipping, cancellation, immutable results and work limits. Before inference, the
recorded lane chooses the first six entries of the existing fixed labeled ASR
subset, joins them with 0.3 seconds of silence and creates a second copy with
2.37 seconds leading silence. These constructed examples exercise boundaries;
they do not establish accuracy on independent long conversations.

Development-only reference dependencies are pinned in requirements.txt. Prepare
from the existing local subset, then run into new destinations:

```powershell
python tests/whisper/recording/prepare.py --audio artifacts/asr-labeled-20260919/native-whisper/manifest.json --output artifacts/recording-inputs-next
python tests/whisper/recording/generate_rules.py --source artifacts/recording-inputs-next/upstream/decoding.py --output artifacts/recording-rules-next.json
python tests/whisper/recording/generate_reference.py --models models/whisper-large-v3-turbo --inputs artifacts/recording-inputs-next/inputs.json --output artifacts/recording-native-next
dotnet build tests/whisper/recording/RecordingReplay.csproj -c Release --tl:off --nologo -v minimal
dotnet tests/whisper/recording/bin/Release/net10.0/RecordingReplay.dll models/whisper-large-v3-turbo artifacts/recording-inputs-next/inputs.json artifacts/asr-labeled-20260919/native-whisper/manifest.json artifacts/recording-managed-next
```

Prepare downloads only the pinned small original Python source files/license;
models and speech inputs must already be local. Run native and managed inference
sequentially with appropriate memory headroom. The public implementation never
loads Python, Torch or native ONNX Runtime. Archive/native/managed qualification
results are pending for this new mode. Existing full encoder/logit numerical
failures remain documented in [the numerical report](../numerical-20260919.md).
