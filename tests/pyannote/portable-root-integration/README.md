# Gated portable source integration

`run.py` is prepared for the prospective AMD portable integration result.
It refuses to edit root source unless the collected comparison, fixed
performance admission, long meetings and terminal owner checks all pass.
The admitted runtime must be exact Coree9c/Data85. This is a successor to the
unused combined integration helper, whose candidate was not selected.

After admission it applies the reviewed23-file portable patch, builds normal
CLI/backend/tensor projects, compares all3,108Core/697Data methods and public
declarations against the measured candidate, runs complete suites, packs Core
and exercises a separate PackageReference consumer. All public signatures and
dependencies remain unchanged. Prior source files are saved before patching;
the independent `audit.py` snapshots final source for stable historical evidence.

From root use `C:/Python313/python.exe -X utf8 -B` with `run.py`, inspect actual
exit0, then run `audit.py`. Do not run against a pending or failed AMD result.
Output is `artifacts/pyannote-portable-root-integration-20260922` and existing
destinations are refused. The normal root binary identity is reported separately
from the measured candidate; this build does not create another timing result.
