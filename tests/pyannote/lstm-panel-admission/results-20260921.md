# Optional LSTM scratch admission: locally qualified

The isolated pyannote successor declines optional combined weight storage when
its length cannot fit an array, preserving the existing scalar fallback. This
does not change projection arithmetic or add a new performance result. The
frozen AMD candidates retain their original binaries; apply this small shared
change to the candidate selected for production after AMD qualification.

The original private creation method throws `OverflowException` when its two
declared span lengths overflow their checked sum. The new test reaches that
failure before allocation or weight reads. The successor uses a wide sum and
checks `Array.MaxLength` before renting. This is a private admission proof;
no huge public-model failure is claimed. Actual pyannote requests remain
770,048 bytes for the first layer and 1,572,864 bytes for each subsequent layer.
These are requested panel sizes, excluding pool rounding and other memory.
