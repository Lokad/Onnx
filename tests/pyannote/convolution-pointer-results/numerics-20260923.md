# Row pointers and fixed steps preserve AMD convolution outputs

The isolated Core `e776cec2` passes numerical qualification with AVX512 enabled
and disabled. It remains a prototype; no performance improvement is claimed.

Five raw families each retain 2,648 cases, 20 supplementary cases and 10 rejected
inputs in both modes. Original raw/wide/span coverage remains intact. Additional
channel pairs 64/80 and 128/256 cover widths 1–13, heights 1/3/7, both strides,
output channels 32/48 and all bias/residual/ReLU combinations. Independent
scalar and production comparisons, prepared graph outputs, sentinels, scratch,
read-only inputs and retained-output ownership pass. Every bit and NaN-payload
comparison reports zero differences.

All 108 captured model layers pass in each mode, covering 119,823,360 values.
Retained hashes and every original Microsoft ORT error bound pass; maximum
native absolute error is 0.000003814697265625. Consumer inventory permits only
declared Core/channel literals and verifies instruction, branch and exception
targets. Numerical checkers are byte-identical to the preceding qualified
campaign. All 30 jobs and 314 resource observations pass; peak owned RSS is
2,720,800,768 bytes. All recorded workers are terminal.

A separate four-process current/candidate × 256/512 campaign passes 25,600
graph executions. Each process covers 1,280 cases: input channels 64/80/128/256,
output channels 32/48, height 3, widths 7/13, both strides, five finite patterns
and eight epilogues. Patterns cover extreme magnitudes, subnormals, signed
zeros, overflow and cancellation. Current/candidate hashes and graph records
match exactly within each mode, including NaN payloads. Ownership, scratch and
read-only checks pass. The exact qualified ConvExtremes executable is reused;
no driver or product is rebuilt. All four jobs and 41 resource observations
pass; peak owned RSS is 85,950,464 bytes.

Between-job pauses came from memory hovering below the fixed 12 GiB preflight.
Completed M27 copies and two unused build package caches were retired after
archive verification and dependency checks. Restore manifests preserve every
removed file. Resource limits and numerical criteria remain unchanged; these
durations are not timing results.
