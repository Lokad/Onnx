## Changes and branch selection

Only `MathOps.cs` and `TensorOps.ConvPool.cs` change in isolated product sources.
The successor shares each source row across kernel taps and copies contiguous
stride-one interiors with `ReadOnlySpan<float>.CopyTo`. It applies the same
copy primitive to the existing 32-float matrix packing panels. These adapt the
ideas from voice `de60581`/`e802581` and `b8849e2`; they introduce no new matrix
arithmetic, activation approximation, cache or forced JIT setting.

Both copy boundaries are clamped so a tile entirely inside padding writes only
its destination. Destination pointers remain inside the allocated tile, and
source-coordinate intermediates use long integers. Strided expansion keeps
coordinate-based scalar copies. The expanded scratch planner checks reduction,
spatial products and combined rental length before use. Ceiling division avoids
an overflowing addition; empty outputs return without a needless scratch rent.
Ordinary block sizes and full-reduction arithmetic remain unchanged.

The branch's `cdeae16` row-sharing path requires AVX-512. This workstation lacks
that hardware, so it is not included or claimed as locally qualified. Current
MatMul already packs the dominant small tile products; a later AMD adaptation
must reuse its current kernels rather than blindly replay the older dispatcher.

## Qualification

All 72 graph arrays / 11,668,428 values match the first baseline's bits exactly,
including all repeated and profiled results. All pass unchanged native scaled
`1e-4`, maximum error `3.859400749206543e-5`. Public speaker decisions, intervals,
centroids, inputs and held outputs pass all 64 calls. Prior current-product
arrays also remain bit-identical. The known silence discrepancy is not repaired
or removed by these recorded-dialogue checks.

The candidate passes 141 focused convolution/spatial tests and 28 focused tests
with hardware intrinsics disabled. New cases cover signed zero, NaN/infinity
payloads, padding-only tiles, partial rows, dilation/stride, panel tails,
destination canaries and scratch overflow without huge allocations. Existing
independent double convolution cases remain. The imported concurrency test uses
Auto with two threads instead of requiring unavailable FMA on fallback hardware.

The complete isolated backend suite passes **3,129**, with 93 skipped; tensors
pass **342**. All builds have zero warnings/errors. The archive includes its
solution root marker, so these suites scan the intended isolated source tree.

The unchanged e5/DINOv3/ResNet50/GPT-2 consumer passes all **166 arrays /
5,000,814 values**, maximum native error `1.9885599613189697e-5`. Every e5 output
retains its prior bits. Graph mutation, fingerprint-disabled execution,
Default/Memory/context paths, decoder state, inputs and held outputs pass.

All 1,892 comparison resource samples and 85 shared-model samples pass. The
first comparison worker waits 40 seconds for the unchanged 10 GiB available
RAM preflight, and the shared-model worker waits 20 seconds. No sample is
discarded. Sampled peak RSS is 1,409,044,480 bytes for baseline and
1,379,332,096 bytes for candidate. All eight supervisor/worker identities are
terminal. No inference from this experiment ran on the occupied AMD VM.
