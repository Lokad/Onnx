# M22 LSTM input-row integration: normal root and package verified

The admitted four-row LSTM input projection is integrated into ordinary root
source. Its [matched application campaign](../lstm-input-app-amd/results-20260922.md)
reduces Pyannote dialogue latency **3.76%**, to **12.666234 s versus Microsoft
ORT 8.944010 s**, ratio **1.416170**. This build verification adds no timing claim.

Exactly five source/test files change: `CPUExecutionProvider.LstmPanels.cs`,
`CPUExecutionProvider.Recurrent.cs`, new `Zzz.LstmInputBlocks.cs`, new
`LstmInputBlockTests.cs`, and `LstmOutputLaneTests.cs`. Four independent time
rows share weight loads, retaining each output's reduction order, separate
input/recurrent sums and existing gate arithmetic. A private per-call array
adds at most 8 KiB of scratch under existing admission. Reverse valid prefixes,
row tails, mutable weights, held outputs and scalar fallback remain qualified.

The guarded integration verifies the complete application closure, recomputes
its original acceptance gates and checks every root source file against the
qualified source before and after applying the five-file patch. All 416
source/build/test files are then copied from the actual root working tree,
with original bytes, into a fresh AMD build namespace. The only allowed
cross-platform source normalization in the source comparison is text BOM/newline
formatting; binary assets remain byte-exact.

Fourteen monitored jobs pass on AMD, CPU2, SDK 10.0.204 / .NET 10.0.8:

- Normal CLI, backend-test and tensor-test restore/build using the existing
  offline feed; no changes to package dependencies or build configuration.
- All **3,163 Core / 697 Data methods** and public declarations exactly match
  the measured candidate, with no renamed compiler methods or excluded changes.
- **3,432 backend passes / 41 existing AMD skips**, and **343 tensor passes**.
  Full test censuses match preceding AMD tests plus 36 new LSTM cases; the
  required AVX-512 independent-oracle test passes.
- Actual NuGet packing and independent PackageReference consumption. The
  package contains the exact built Core and only Google.Protobuf 3.33.5.
  Public operators, MNIST import/execution, inputs and held outputs pass.
  Prepared ConvRelu also passes 1,056 values over two calls, 18,432 retained
  weight bytes and 8,384 scratch bytes.
