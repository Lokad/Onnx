The isolated prototype replaces generic dispatch only for the validated
sigmoid/tanh/tanh update with bias, no clipping or peepholes, and uncoupled
input/forget. It uses the existing scalar MathF expressions and addition
order, preserves the generic loop verbatim and adds no scratch. It starts
from the current product; the rejected wider projections are not included.

compiled inventory permits exactly one changed existing method, Lstm, and
one new private LstmUpdateDefaultGates helper. The other 3,162 existing Core
methods, all 697 Data methods and public declarations remain identical.
