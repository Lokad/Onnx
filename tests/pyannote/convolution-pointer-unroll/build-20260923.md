# Row pointers with fixed spatial steps: isolated AMD build passes

The new prototype combines row pointers with nine explicit spatial steps in
the six-position AVX512 convolution tile. It preserves each output's original
FMA order, twelve accumulators, weight traversal, stores and tail behavior.
Kernel256 and all graph preparation/dispatch code remain unchanged.

The normal Linux build passes using SDK 10.0.204 and runtime 10.0.8. Independent
compiled inventory confirms that only Kernel512 changes: all other 3,162 Core
methods, all 697 Data methods and public declarations match the measured
current product. No methods are added or removed. All four jobs and 74 resource
observations pass; peak owned RSS is 498,798,592 bytes. All owners are terminal.
All 416 qualified root source files remain unchanged.
