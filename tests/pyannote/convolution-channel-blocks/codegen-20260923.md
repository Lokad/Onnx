# Channel blocks retain arithmetic but enlarge the optimized kernel

The current and candidate AMD kernels execute the same twelve FMA instructions,
six input broadcasts and two weight loads for each spatial reduction step.
The instruction sequence is identical except for stack offsets. The candidate
loads prior output before continuing later input-channel blocks and guards all
second-output-vector reads. Its final spatial tail retains separate multiply
and add instructions. The optimized loop has no vector stack references;
twelve entry loads restore state when execution moves into optimized code.

| Emitted code | Current Core2083 | Candidate Core8e0 |
|---|---:|---:|
| Instrumented Tier0 bytes | 3,756 | 5,669 |
| Tier1-OSR bytes | 2,176 | 3,680 |

The optimized method grows 69.1%, with additional partial-output loads, stores
and guards. Reusing weights therefore has a concrete overhead to overcome.
These instruction counts and code sizes do not establish a speedup.
