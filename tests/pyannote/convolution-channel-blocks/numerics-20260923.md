# Channel blocks preserve convolution results on AMD

The isolated candidate passes expanded convolution checks with AVX512 enabled
and disabled. It is not integrated and has no new performance result.
Current Core is `208371f6`; candidate Core is `8e0ff60c`.

Five raw families each cover 2,648 cases, 20 supplementary cases and 10 rejected
inputs in both instruction modes. The original raw/wide/span families remain
intact. Two additional families cover input channels 64/80 and 128/256, widths
1–13, heights 1/3/7, both strides, output channels 32/48 and all eight
bias/residual/ReLU combinations. Scalar and production references, prepared
graph outputs, read-only inputs, retained outputs and scratch checks all pass,
with zero bit or NaN-payload differences.

Each of the 108 captured model layers passes in both modes: 119,823,360 values
per mode preserve retained output hashes and every Microsoft ORT error bound.
Maximum native absolute error is 0.000003814697265625. This is numerical
conformance, not a new ORT timing baseline.

Compiled consumer inspection confines changes to the Core hash and, in the
two new families, declared channel constants. It verifies every instruction,
including branch/exception offset changes caused by wider constants. Three
checker tests reject 18 deliberate consumer/census mutations. All 30 jobs and
316 resource observations pass; peak owned RSS is 2,777,886,720 bytes.

The original supplementary driver fixes channels at 32. A separate test closes
that coverage gap using the unchanged qualified GraphRaw caller and a new
public-API driver. Four fresh current/candidate × 256/512 processes each cover
1,280 cases: channels 64/80/128/256, output channels 32/48, height 3, widths 7/13,
both strides, five finite patterns and eight epilogues. Patterns cover finite
extremes, subnormals, signed zeros, overflow and cancellation across blocks.
All 25,600 graph executions pass. Current/candidate output hashes and graph
records are exact within each instruction mode; all NaN-payload differences
are zero. Scratch, ownership and input immutability checks pass. All seven
jobs and 60 resource observations pass; peak owned RSS is 324,165,632 bytes.

The first extreme-value runner was staged but never launched: source inspection
found its missing AVX512-disable assignment. Its immutable artifacts are kept
with `superseded-before-launch.json`. The corrected v2 runner uses fresh
namespaces; the driver, products, coverage and limits are unchanged. Earlier
numerical staging also deferred before creating its VM directory because the
12 GiB memory preflight was not met. Neither attempt produced samples.
