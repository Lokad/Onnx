# Combined AVX-512-first pyannote source: local qualification

The actual combined source builds with normal project references and passes
local qualification. It tries the previously AMD-qualified AVX-512 convolution
helper before the newer portable kernel, while retaining output pooling,
request contexts, sparse mel filters and the checked LSTM panel guard.
This is preparation evidence; it supplies no new latency or AMD execution claim.

Compared with the qualified portable-only normal source, three files change:
TensorOps.ConvPool.cs and the unchanged packed-row helper and tests. The compiled
review identifies three new helpers, the two convolution methods and the parallel
call site. All other 3,105 Core methods and all 697 Data methods are unchanged.
Every public declaration is equal. The generated static-initializer lambda shifts
from ordinal 532 to 535; its exact body and its single renamed reference were
verified before normalization. Portable fallback wrapper construction is retained.

Focused tests pass 219 with two AVX-512 skips. Hardware-disabled tests pass 55
with the same two skips. The complete backend suite passes 3,295 with 95 skips;
all 342 tensor tests pass. The required AVX-512 tests must execute on AMD.
A separate PackageReference consumer loads the exact packaged core and passes
matrix, convolution, fused activation, ownership and MNIST-import checks.
Only Google.Protobuf 3.33.5 is a package dependency.

All 447 build/test/consumer resource samples pass their fixed bounds; peak owned
RSS is 4,066,500,608 bytes. Both supervisors and all recorded descendants are
terminal. Preparation session 2103 and qualification session 97517 exited zero.
