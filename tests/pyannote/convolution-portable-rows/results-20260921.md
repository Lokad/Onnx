## Implementation

Only the matrix call inside tiled float convolution changes. Eligible tiles
pack once, use the existing three-row kernel for a multiple of six rows and
use the existing two-row kernel for the remaining two or four rows. Short
reductions retain their previous path, following the
[closed kernel experiments](../portable-row-groups/results-20260921.md).
The independent kernel study's17.8%geometric-mean reduction is not an application
speedup and is not extrapolated here.

Admission requires SIMD/intrinsics/FMA, even output rows of at least32that are
not divisible by3, reduction at least64and positive output width. It preserves
the original packing size limits and declines when the explicit dynamicAVX512
experiment is enabled. Pointwise convolution, full-patch convolution, generic
matrix dispatch and raw arithmetic kernels are unchanged. The helper validates
all spans before mutation, clears the requested output, accounts for packing
scratch and returns its rental through `finally`.

The [candidate patch](candidate.patch) changes one existing Core method and adds
two helpers. The independent method inspector verifies **3,104 other Core
methods and all696Data methods unchanged**, comparing resolved instructions,
locals, stack requirements and exception clauses. The compiler renames one
static-initializer helper from ordinal530to532; its body is identical and its
constructor differs only in that one resolved method operand. No other method
change is allowed. Data remains byte-identical.
