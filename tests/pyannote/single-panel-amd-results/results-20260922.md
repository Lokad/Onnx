Core `1279b4b6` / Data `4e602d9f`. It writes eligible grouped convolution rows
directly to final output, with the qualified two-column helper. Patches of at
most 32 columns already have the packed layout; the candidate reads them directly
without a packed-array rental or copy. Wider patches retain the existing packing.
Remaining rows use the existing kernel and bias/copy sequence. Numerical kernels,
tensor views, public APIs and packing limits retain their qualified behavior.

declarations. Complete suites pass 3,365 backend tests

is preserved, with NaN classification preserved and payload differences recorded.

Fresh qualification covers both managed roles: 36 Pyannote graph arrays /
