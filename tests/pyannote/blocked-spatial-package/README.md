# Independent public package consumer

After normal-source v3 closes successfully, run `C:/Python313/python.exe -X utf8
-B` with `run.py`, then `audit.py` after terminal success. Existing destinations
are refused. This packs the qualified normal project with `--no-build
--no-restore`, then consumes the actual nupkg from a fresh NuGet cache.

The package must contain the exact qualified Core and retain only the existing
Google.Protobuf 3.33.5 dependency. The consumer has no project or direct assembly
reference. It checks public operators/import, and a prepared ConvRelu graph through
an independent execution context: 1,056 exact values on each of two calls, held
output and operand ownership, 18,432 retained weight bytes and 8,384 requested
scratch bytes proving eligible dispatch. The previous source/binary pins must
remain unchanged after packing. Resource and process-identity checks remain.

This qualifies package distribution and public execution, not full-model behavior
or speed against Microsoft ORT.
