# Pyannote kernel changes preserve Parakeet's full decoder trajectories

The isolated convolution/LSTM candidate preserves **all 784 arrays and
3,090,494 values bit-for-bit** against the current production runtime in the
original Parakeet consumer. All public decisions, input/output ownership,
invalid-request and cancellation checks pass. This is a shared-kernel
regression pass; the three known Windows ORT numerical failures remain.

| Check | Production baseline | Optimized candidate |
|---|---|---|
| Public application contracts | Pass | Pass |
| Captured arrays / values | 784 / 3,090,494 | 784 / 3,090,494 |
| Native numerical gate | Fail: three arrays | Fail: same three arrays |
| Maximum scaled native error | 0.0002321004867553711 | 0.0002321004867553711 |
| Maximum difference from baseline | — | 0, all bits identical |
| Sampled peak RSS, bytes | 5,759,553,536 | 6,368,993,280 |

The failing array is duration output `outputs` at decoder step 26, index 8193,
for English, the frame-limit case and the English repeat. Both workers correctly
exit with code 1 for numerical failure. The supervisor and independent auditor
retain this verdict separately from the regression result; the `1e-4` bound
is unchanged. The candidate introduces no new failure and worsens none.

## Scope

Windows i7-14700KF, logical CPU2 before CLR startup, .NET 10.0.12, normal runtime
settings. Two fresh workers run sequentially, production then candidate. The
original frozen `TranscribeReplay` consumer covers English, French, JFK,
token/frame limits, silence and repeat. Six invalid/cancelled requests and
successful recovery are included. The decoder advances its own managed state
through the full encoder/decoder trajectory; native state is not substituted.

The independent NumPy auditor checks every saved tensor against the original
ORT 1.29.0 fixtures and recomputes all baseline/candidate comparisons. Full
application results also match between cores. Models, the Data assembly,
consumer and native references retain their original bytes. No native run or
matched performance experiment was performed, and the two process durations
are not used as a speedup claim. Sampled memory is a finite observation with
all 127 samples retained; both workers remain below the 8 GiB guard.

Other limits are 1,800 seconds per worker, 1 GiB available RAM, 10 GiB preflight
RAM and 20 GiB free disk. All samples pass; supervisor and workers are terminal.
The broader numerical limitations remain in [model support](../../../docs/model-support.md)
and the [original complete trajectory check](../../parakeet/transcribe/README.md).
