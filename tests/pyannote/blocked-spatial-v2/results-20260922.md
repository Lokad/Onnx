# Direct spatial convolution: numerical qualification

The isolated prototype passes Windows AVX2 and AMD AVX2/AVX-512 numerical
qualification. No component or application performance has been measured, and
product dispatch is unchanged. Pyannote remains first, Parakeet second, and
Whisper deferred.

The prototype reads padded channel blocks directly instead of materializing
each convolution patch. Twelve accumulators cover six spatial positions and
two output-channel blocks. It preserves selected reduction order, including
separate multiply/add for the final fewer-than-eight spatial positions. The
prospective performance candidate uses sixteen channels per block on AVX-512;
the eight-channel path provides portability evidence.

| Corrected Windows AVX2 | 2,648 | 20 | 10 | Pass |

All 2,496 finite cases in the first implementation match both an independent
ordered scalar reference and selected public Conv/Add/Relu exactly. Its special
cases expose NaN payload differences: 864 scalar and 4,394 production bit
differences across 146 cases. Every observation remains in the failed artifact;
only the first mismatch per case is classified by the report.

The explicit v2 successor retains the generated arithmetic. It scans input,
prepared weights, bias and residual for non-finite operands, then delegates
those calls to the selected public implementation. Each eventual timed call must
include these scans. This preserves all 152 original non-finite cases. Sixteen
extra cases isolate NaNs in individual operands, and four finite overflow cases
exercise the new kernel. Guards, unaligned offsets, read-only operands and held
owned outputs pass. AMD reports match every Windows observation exactly.
