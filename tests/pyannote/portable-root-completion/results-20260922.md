## Preserved source-policy failure and correction

The first root tensor run passed 341 tests and failed the repository-wide optional-
parameter scan. It found three old declarations in two immutable experiment inputs:
`tests/pyannote/request-contexts/PipelineRequestTests.cs` and
`tests/whisper/weight-sharing/WhisperDecoderWeightsTests.cs`. Their current
compiled test-project versions already use explicit overloads. No numerical
assertion or AMD selection gate failed.

The policy now recognizes only those two exact relative paths and their normalized
SHA256 content. Any changed archived content fails an assertion; every other
source remains subject to the original scanner, including the current compiled
test copies. A new regression checks changed content, another path and line-ending
normalization. No directory exclusion or numerical tolerance change is introduced.
The historical input files and original failed TRX remain unchanged.

The continuation reuses completed product builds, instruction proof and backend
results. It rebuilds only the tensor tests with BuildProjectReferences=false,
runs all 343 cases, then packs and exercises the independent consumer. Product
binaries remain byte-identical throughout. Final source snapshots include the
23selected product/test files and this one source-policy correction.
