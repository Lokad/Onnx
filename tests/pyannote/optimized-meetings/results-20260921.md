# Optimized pyannote preserves the complete meeting results

The isolated convolution/LSTM candidate passes both original ten-minute AMI
meetings and the 30-second recovery request. Ordinary and exclusive speaker
timelines match the retained Microsoft ORT application outputs exactly in all
three requests. Centroid scaled errors remain below `9e-7`; input preservation,
owned outputs and held-result stability also pass.

| Request | Audio seconds | Managed request seconds | Maximum centroid scaled error | Both timelines |
|---|---:|---:|---:|---|
| ES2004a | 600 | 383.5465575 | 8.981409564540188e-7 | Exact ORT match |
| IS1009a | 600 | 346.9975485 | 5.764390146878462e-7 | Exact ORT match |
| ES2004a recovery | 30 | 12.6271569 | 5.18795691045737e-7 | Exact ORT match |

These are single correctness replays on Windows i7-14700KF, logical CPU2,
.NET 10.0.12, normal runtime settings. The unchanged public consumer retains
one model across both meetings and recovery. No native inference or matched
performance comparison was rerun. These request durations do not establish
a speedup against the earlier AMD observations or an ORT latency ratio.

The candidate combines [spatial panels](../spatial-panels/results-20260921.md),
[contiguous copies](../spatial-copy/results-20260921.md) and
[ordered LSTM output lanes](../lstm-output-lanes/results-20260921.md). It remains
isolated pending AMD qualification and production integration. The Data
assembly, model files, input waveforms and original public consumer are unchanged.

## Accuracy and numerical scope

Exact equality of both complete timelines preserves the original native
human-annotation scores: aggregate ordinary DER **21.4593%** and exclusive
DER **24.7763%**. DER is missed, falsely detected and confused speaker time
divided by reference speaker time. The original scoring includes overlap and
uses no boundary collar. These are the same two fixed excerpts; no new human
annotation or scoring run is claimed.

| Meeting | Ordinary DER | Exclusive DER |
|---|---:|---:|
| ES2004a | 22.5921% | 25.7048% |

The independent auditor compares every public result field, validates timeline
structure, and verifies the complete waveform hashes. It uses the unchanged
scaled `1e-4` numerical bound. Final timeline agreement does not resolve the
known segmentation silence-tensor failures or qualify every intermediate
tensor of these long requests. See the [original meeting evidence](../natural-meetings/results-20260920.md)
and [model qualification limits](../../../docs/model-support.md).
