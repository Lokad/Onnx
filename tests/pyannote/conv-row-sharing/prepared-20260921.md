# Convolution row sharing prepared for AMD execution

An isolated successor to the qualified convolution/LSTM core now selects the
existing AVX-512 row-sharing composer specifically for tiled convolution.
Local preparation passes: **148 focused tests, 3 skipped**, and **37 tests
with hardware intrinsics disabled, 2 skipped**. The skipped tests require
AVX-512 execution, which this i7 workstation does not support. No new-path
execution, application speedup or production promotion is claimed.

The adaptation uses the mechanism from voice `cdeae16`, with current
`MathOps.TryPackedAvx512Rows` and its existing 12/8-row groups and 3/2-row
remainders. The branch's old composer is not imported. Only convolution
selection and a new `TensorOps.ConvPackedRows.cs` helper change; matrix
arithmetic, recurrent code, activation handling and generic e5 switches stay
unchanged.

Eligible tiles have at least eight output channels per group and a column
count divisible by 32, with SIMD, intrinsics, AVX-512F and FMA available.
Each group packs its expanded input once, clears its output tile, and invokes
the existing composer. Other hardware, execution options and column tails
retain the existing matrix dispatcher. The new integration tests cover grouped,
strided and dilated convolution, partial tiles, mutable weights, held outputs,
unsupported-path refusal without writes, and checked optional storage.

One group's packing space is carved from the existing batch rental and counted
in requested scratch bytes. If that addition exceeds the supported array
length, optional packing is declined. For the dominant 32-channel 3×3 shape,
the 192-column tile requests **466,944 bytes** including packing; the earlier
245,760-byte convolution rental excluded matrix packing. The 256 KiB spatial
planner is not a hard cap on all scratch. Actual AMD scratch accounting and
output clearing have explicit execution tests awaiting that host.

accessor. The corrected successor uses the public `Dimensions` property;
product source is identical between attempts. The failed source/logs remain

No tests or model inference ran in that failed attempt.
