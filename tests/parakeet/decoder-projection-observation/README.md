# Observe the actual decoder projection before selecting a change

This observer is being prepared locally. It has not been compiled, staged or
executed. No new performance candidate or campaign is prepared. Finish the fixed
rational sigmoid release qualification first, then bind its actual root product
through that qualification's complete compiled-equivalence proof.

The decision is whether the final one-row projection should consume its existing
packed B. Use exactly the first `english-16k` decoder step from the closed rational
model qualification. `fixture.py` checks retained byte identities and derives the
original encoder frame and zero recurrent states; it performs no inference and
writes no files. It preserves all four complete expected outputs. Its descriptor
deliberately has no executable `core_sha256` binding until actual root qualification.
The nine input/expected files total 57,380 bytes. Seven local fixture tests pass,
including frame reconstruction and refusal of corrupt, nonfinite, ambiguous,
wrong-product, wrong-layout or noninitial-state data. The marker implementation
matches the existing collector's provider and payload exactly after whitespace
normalization. These checks do not replace VM compilation or a runtime result.

`Driver.cs` loads the original decoder with the ordinary 64 MiB preparation
budget and `ExecutionOptions.Memory`. It records the actual prepared map, source
array/reference relationships, tensor shapes/strides/hashes and retained bytes.
Missing packing is a finding, not a failed hypothesis forced into a passing check.
One separate context retains the projection operands through local output bindings;
ordinary control calls before and after must preserve every original output.
The sampled context has only the original model outputs. All graph nodes and
initializers must remain unchanged, and held results must survive later calls/reset.

Use two fresh diagnostic processes, control then trace, with the same consumer,
fixed input, 256 warmups and 1,024 observed calls. Every call checks all original
output bytes outside its marked interval. This validation allocates and may affect
subsequent collection behavior; retain those effects and never use these clocks
as a performance score. All allocation/copy/scratch counters describe the entire
decoder, not the final node. Zero counted copies can exclude a counted copy;
nonzero totals cannot attribute a copy to a node.

Reuse the existing `dispatch-events-amd` collector, all-event exporter and stack
conversion. The marker provider/payload matches that collector; the markers now
bound whole original decoder calls with fixture zero. Ordinary runtime flags and
tiering remain; do not force an ISA, disable pooling, force GC or alter inlining.
Associate samples with their actual managed methods/versions and retained call
intervals. Missing or ambiguous samples stay explicit. A JIT listing alone does
not show which version served every call. No additional native trace is required
unless its missing association could change the intervention.
