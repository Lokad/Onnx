# Twenty-recording speech accuracy observation

Both managed recognizers match their independent native application results on
all twenty selected recordings and the repeated first request. Against the
human transcripts, Parakeet has 11 word errors and Whisper Large V3 Turbo has
10. The one-word difference does not establish a general model ranking.

| Measure | Parakeet | Whisper Large V3 Turbo |
|---|---:|---:|
| Word errors / 559 reference words | 11 / 559 | 10 / 559 |
| Word error rate | 1.9678% | 1.7889% |
| Substitutions / deletions / insertions | 10 / 0 / 1 | 8 / 1 / 1 |
| Character errors / 3,017 reference characters | 13 / 3,017 | 18 / 3,017 |
| Character error rate | 0.4309% | 0.5966% |
| Exact normalized transcripts | 13 / 20 | 12 / 20 |
| Managed/native application agreement | 21 / 21 requests | 21 / 21 requests |
| Token-limit truncations | 0 | 0 |

The [complete observations](observations-20260919.json) retain every human
transcript, actual managed text and per-recording error count. Native and
managed scores are identical. Many counted errors are orthographic: `SOMETIME`
versus `SOME TIME`, `LOVE MAKING` versus `LOVEMAKING`, `MISSUS` versus `MRS`,
spelled versus numeric dates, `COLOR` versus `COLOUR`, and an apostrophe in
`DOVE'S`. Other errors include `FULL` versus `FALL`, a rare vocabulary word and
proper names. None were repaired or excluded after recognition.

The [prospective recipe](README.md) selected twenty clean English test
recordings from ten speakers by numeric speaker ID, lexical recording ID and
two duration bands. They total 213.265 seconds, with individual lengths
4.07–17.96 seconds. Selection predates inference. Source is the CC-BY-4.0
[LibriSpeech dataset](https://huggingface.co/datasets/openslr/librispeech_asr/tree/71cacbfb7e2354c4226d01e70d77d5fca3d04ba1/clean/test)
at revision `71cacbfb7e2354c4226d01e70d77d5fca3d04ba1`, pinned in
[dataset.json](dataset.json). This is a diagnostic subset, not the official
full test benchmark; test-split membership does not prove absence of related
training data.

Normalization was fixed before inference: Unicode NFKC, uppercase,
letters/numbers/internal ASCII apostrophes, other characters to spaces, then
collapse whitespace. There is no model-specific normalization, number
expansion, abbreviation mapping or spelling repair. CER includes normalized
spaces. Rates aggregate errors and reference lengths. A separate dynamic
program independently verifies JiWER's total edit distances; reported edit
categories come from one optimal JiWER alignment. No acceptance threshold or
confidence claim was fitted to these results.

Both public PCM APIs used their normal production defaults on Windows,
.NET 10.0.12. Parakeet used limits 4096 tokens / 10 emissions per frame;
Whisper used English transcription, a 444-token cap and its default
no-speech policy. Each process retained earlier actual inputs and returned
results through all subsequent requests, verified them unchanged, repeated
the first recording, and rejected a loaded native ORT module. All requests
ended normally. Parakeet matched tokens, frame positions, duration predictions,
stop reason and decoder-call counts; Whisper matched tokens, text, stop reason
and no-speech decisions.

Native references used CPU ORT 1.29.0, one thread and no spinning. Parakeet's
separate recurrent trajectory also agrees with the pinned upstream greedy
loop. The audit recomputed Whisper's token selection, suppression, probability
and text decisions from every saved native logit array. This application check
does not compare complete managed/native intermediate tensors.

Four sequential, CPU-2-bound local processes ran with normal runtime settings,
no forced GC and a sampled 20-GiB/7,200-second process guard. Observed peaks were
9,594,392,576 bytes for managed Parakeet and 12,269,314,048 bytes for managed
Whisper. Native peaks were 2,785,325,056 and 5,262,196,736 bytes respectively.
These are finite observations for this sequence, not matched latency
benchmarks or universal memory bounds.
No AMD inference or I/O ran for this audio milestone.
